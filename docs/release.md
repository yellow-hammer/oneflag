# Выпуск релиза

1. Убедиться, что `opm run test` проходит локально и в CI.
2. Обновить `CHANGELOG.md`: перенести накопленное из раздела `Не выпущено` в новую версию.
3. Поднять версию в `packagedef` по [semver](https://semver.org/lang/ru/).
4. Закоммитить изменения и создать тег: `git tag v<версия>`, `git push --tags`.
5. Создать релиз на GitHub с тегом версии. Workflow `release.yml` соберёт пакет
   и опубликует его в hub.oscript.io.

## Требуемые секреты репозитория

| Секрет | Назначение |
|---|---|
| `PUSH_TOKEN` | Токен hub.oscript.io для публикации пакета |
| `TRIGGER_DOCS_DEPLOY_TOKEN` | Токен запуска публикации документации |

## Проверка после публикации

```
opm install oneflag
```
