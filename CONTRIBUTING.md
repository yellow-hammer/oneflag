# Как внести вклад

Спасибо за интерес к проекту.

## Быстрый старт

```
git clone https://github.com/yellow-hammer/oneflag
cd oneflag
opm run install
opm run test
```

## Перед тем как открыть pull request

- Прогнать `opm run test`: все тесты должны проходить.
- Покрыть новую функциональность тестами в `tests/`.
- Обновить `README.md` и `CHANGELOG.md`, если менялось поведение или публичный API.
- Соблюдать стиль кода: русские ключевые слова, отступ табом, пустая строка перед `Возврат`,
  комментарии объясняют «почему», а не пересказывают код.

## Соглашения

- **Коммиты** - [Conventional Commits](https://www.conventionalcommits.org/ru/v1.0.0/):
  `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`.
- **Именование**: модули и классы - английские имена (совпадают с терминологией стандарта),
  методы и переменные - русские.
- **Обратная совместимость**: сигнатуры экспортных методов не меняются без веской причины.
  Ломающее изменение описывается в `CHANGELOG.md`.

## Сообщить об ошибке

Заведите issue по шаблону: что сделали, что ожидали, что получилось, версии
`oneflag`, OneScript и ОС.
